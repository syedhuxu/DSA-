Step 0: Initial Empty Tree

An AVL Tree is a self-balancing Binary Search Tree where every node maintains a Balance Factor (BF):

BF(node) = Height(Left) - Height(Right)

If inserting a node causes any ancestor's |BF| > 1 (i.e. +2 or -2), we rebalance the tree at the lowest unbalanced ancestor using one of 4 rotations: LL, RR, LR, or RL.

How AVL Tree Rotations Work (LL, RR, LR, RL)

After standard BST insertion, we walk back up from the newly inserted leaf toward the root, updating heights and checking BF = Height(Left) - Height(Right). Let z be the first (lowest) ancestor with |BF| = 2, y be the taller child of z along the insertion path, and x be the grandchild along the insertion path.

1. Left-Left (LL) Case BF(z) = +2, BF(y) ≥ 0

Cause: Insertion occurred in the left subtree of the left child of z.

Fix: Single Right Rotation around z. 

      z (+2)                           y (0)
     /                                /     \
    y (+1)    == Right Rotate(z) ==> x       z (0)
   /
  x (new)     (Occurs in dataset at: Insert 7 & Insert 4)
2. Right-Right (RR) Case BF(z) = -2, BF(y) ≤ 0

Cause: Insertion occurred in the right subtree of the right child of z.

Fix: Single Left Rotation around z. 

  z (-2)                                 y (0)
   \                                    /     \
    y (-1)    == Left Rotate(z) ==>    z (0)   x
     \
      x (new) (Occurs in dataset at: Insert 60 & Insert 20)
3. Left-Right (LR) Case BF(z) = +2, BF(y) = -1

Cause: Insertion occurred in the right subtree of the left child of z (zig-zag path).

Fix: Left Rotate(y), then Right Rotate(z). 

    z (+2)             z (+2)               x (0)
   /                  /                    /     \
  y (-1)  =Left(y)=> x (+1)  =Right(z)=>  y (0)   z (0)
   \                /
    x              y         (Occurs in dataset at: Insert 8 & Insert 16)
4. Right-Left (RL) Case BF(z) = -2, BF(y) = +1

Cause: Insertion occurred in the left subtree of the right child of z (zig-zag path).

Fix: Right Rotate(y), then Left Rotate(z). 

  z (-2)             z (-2)                  x (0)
   \                  \                     /     \
    y (+1) =Right(y)=> x (-1) =Left(z)=>   z (0)   y (0)
   /                    \
  x                      y   (Occurs in dataset at: Insert 12 & Insert 19)
